# ADR-0018 微信能力单独分发、默认不安装

- **状态**：Proposed（需法务独立评审）
- **日期**：2026-11-08
- **决策者**：架构组 + 法务 + 产品
- **关联**：`09` §2、`11` §7、`14` WBS 18 / R-13

## 背景

微信侧两类能力性质不同：公众号视频可解析公开 HTML，风险较低；**视频号没有公开 API**，需微信 PC 客户端 + 本地 MITM 代理 + JS 注入 + 私有加密解密（参考 `wx_channels_download`、`res-downloader`）。其中「安装根 CA / 修改系统代理 / 注入 JS」需要管理员权限与系统级副作用，且逆向规则高频变更，涉及平台条款与合规风险。

## 决策

1. 微信能力作为**独立可选插件**立项，**单独分发、默认不安装**，不进主安装包与默认功能列表。
2. **MITM 转发本体不是 sidecar**：`goproxy` 是 Go 库，代理逻辑可跑在核心/插件进程内；只有「装/卸根 CA、改系统代理、注入 JS、热更新逆向规则包」需要**独立提权助手**进程，权限与风险与主进程物理隔离，每次提权操作需显式用户授权。
3. 桌面端限定；移动端不提供该能力（无法派生子进程、无法安装系统 CA）。
4. 规则包走独立更新通道并签名校验；插件整体可一键卸载并完整清理 CA、代理设置与注入脚本。
5. **不碰 DRM**（Widevine / FairPlay / PlayReady），不提供会员内容绕过；能力限定为下载用户有权保存的内容。
6. 若法务否决，整体移除该功能，不影响主程序任何能力（`14` R-13 应急）。

## 备选方案

| 方案 | 结论 |
|---|---|
| 随主包内置微信嗅探 | ❌ 合规风险扩散到整个产品、影响商店上架与签名 |
| 把整个 `goproxy` 代理外置为 sidecar | ❌ 它是 Go 库，本体可进程内；只有提权部分需要外置 |
| 用移动端 MITM | ❌ iOS/Android 无法安装系统 CA / 派生子进程，且违反商店规则 |
| 完全砍掉微信能力 | 可接受；产品判断是否值得独立立项（OPEN-06） |

## 后果

**正面**：风险与主程序物理隔离；主包上架、签名、许可证清单不受影响；可随时下线该能力而不动核心。

**负面**：用户安装门槛高（需授权安装 CA、信任证书）；规则失效频繁；桌面端限定；需要独立合规评审与卸载清理逻辑。

## 合规与验证

- 主安装包中不含该插件与提权助手；`/capabilities` 默认显示 `unavailable`。
- 卸载后验证：根 CA 已移除、系统代理恢复、无残留注入脚本与进程。
- 法务逐条审阅平台条款并签字；`16` §7 规定主包功能列表不得列出该能力。
- 不提供任何 DRM 规避能力，安全评审列入 `11` §7 检查。
