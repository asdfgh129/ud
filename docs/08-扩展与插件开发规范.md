# 08 扩展与插件开发规范

> 文档编号：UD-DOC-08 ｜ 版本：v0.1 ｜ 状态：草案 ｜ 日期：2026-11-08 ｜ 相关：ADR-0014、`11` §3

## 1. 扩展点总览

| 扩展点 | 用途 | 默认运行时 | 是否可热更新 |
|---|---|---|---|
| `Resolver` | 新增链接封装 / 站点解析 | 进程内 Go / goja 插件 | ✅ 规则包 |
| `Transport` | 新增传输协议 | 进程内 Go（不建议插件化） | ❌ 需发版 |
| `PostProcessor` | 新增后处理（Remux 变体、Transcode） | 进程内 Go / sidecar 适配 | 部分 |
| `SourceRule` | 站点规则（选择器、签名、格式提取） | goja（ES5.1）/ 可选 WASM | ✅ 独立通道 |
| `CredentialProvider` | 凭据获取方式 | Go | ❌ |

> 原则：**Resolver 处理不可信输入，插件必须默认无网络、无文件、无环境变量能力**，能力按 manifest 显式授予。

## 2. 插件 manifest

```json
{
  "name": "site.example",
  "version": "1.2.0",
  "apiVersion": "ud.plugin/v1",
  "type": "resolver",
  "runtime": "goja",
  "entry": "index.js",
  "match": ["^https?://([^/]+\\.)?example\\.com/video/"],
  "capabilities": {
    "http": { "allowedHosts": ["example.com", "*.cdn.example.com"], "maxRedirects": 3 },
    "fs": false,
    "env": false,
    "subprocess": false,
    "crypto": ["sha256", "base64"]
  },
  "limits": { "timeoutMs": 10000, "memoryMB": 32, "maxResponseBytes": 1048576 },
  "signature": "ed25519:BASE64...",
  "author": "...", "license": "MIT"
}
```

| 字段 | 约束 |
|---|---|
| `runtime` | `goja`（起步）或 `wasm`（wazero/Extism，硬隔离） |
| `capabilities.http.allowedHosts` | 必填白名单；空数组 = 完全无网络 |
| `subprocess` / `fs` / `env` | Resolver 插件默认 `false`，开启需安全评审 |
| `limits` | 强制超时、内存与响应大小上限 |
| `signature` | 官方仓库插件必须 Ed25519 校验；本地开发可 `--insecure-plugins` |

## 3. goja 插件契约

```javascript
// index.js —— 声明式站点规则
export const meta = {
  name: "site.example",
  version: "1.2.0",
  match: [/^https?:\/\/([^/]+\.)?example\.com\/video\//]
};

// ctx 由宿主注入，只有白名单内的能力
// ctx.http.get(url, {headers}) -> {status, body, headers}
// ctx.log.info(msg) / ctx.base64.decode(s) / ctx.sha256(bytes)
export function resolve(url, ctx) {
  const html = ctx.http.get(url, { headers: { "User-Agent": "UD/1.0" } }).body;
  const m = /"playUrl":"([^"]+)"/.exec(html);
  if (!m) throw new Error("RULE_OUTDATED: playUrl not found");
  return {
    files: [{ index: 0, path: "video.mp4" }],
    mirrors: [{ url: unescape(m[1]), priority: 1 }],
    headers: { "Referer": url },
    identity: { isAdaptive: false }
  };
}
```

**宿主义务**：① 用 `ResolveContext.Guard` 校验所有产出 URL；② 注入的 `ctx.http` 只能走白名单且逐跳校验重定向；③ 捕获 panic 并转为 `E_RESOLVE_FAILED`；④ 规则抛 `RULE_OUTDATED` 时上报并尝试兜底 Resolver（yt-dlp）。

> goja 仅支持 **ES5.1**：不得使用 `async/await`、可选链、`fetch`、ES Module 语法（宿主做转译包装）。需要现代 JS 或强隔离时改走 WASM。

## 4. WASM 硬隔离（可选进阶）

| 方案 | 特点 |
|---|---|
| `wazero`（纯 Go，零 cgo） | 进程内 WASM 运行时，可精确裁剪 WASI 的 `net`/`fs`/`env` 能力，保持单二进制 |
| `Extism` | 插件 SDK 成熟、跨语言（Rust/Go/JS→WASM），便于生态分发 |
| `wazero + QuickJS-WASM` | 可在进程内跑现代 JS 挑战脚本，但工程量大；YouTube 对抗逻辑仍不建议自行维护（ADR-0010） |

选择判据：**规则来源可信度低 / 需要第三方贡献 → WASM**；仅团队自维护的中文站规则 → goja 足够。

## 5. 内置实现的安全优先级

`thunder://` 解码、Metalink 解析、SSRF Guard、凭据脱敏等安全敏感 Resolver **必须内置且不可被插件覆盖**。插件 `Match()` 优先级恒低于内置实现，注册时若 `match` 与内置冲突直接拒绝加载。

## 6. 示例：`thunder://` 解码 Resolver（内置，约 20 行）

```
输入 thunder://BASE64
→ base64 解码 → 校验前缀 "AA" 与后缀 "ZZ" → 取出中间原始 URL
→ 校验 scheme ∈ {http, https, ftp, ed2k} → 构造单文件 Resource
→ 交回自有 HTTP/FTP Transport
```

`flashget://`（首尾加 `[FLASHGET]`）、`qqdl://`（Base64 变体）同理。**迅雷 P2SP / 高速通道 / 离线下载为私有协议，无开源实现，本项目只做解码**（ADR-0007）。

## 7. Metalink Resolver（内置，纯 Go）

- RFC 5854 XML：解析 `<file>`（name、size）、`<url>`（priority、location、type）、`<hash>`、`<pieces>`（type、length）、`<metaurl>`；兼容 v3 旧命名空间。
- RFC 6249 HTTP 头：`Link: <...>; rel=duplicate; pri=; geo=`、`Digest: SHA-256=`。
- 纯 Go 实现（约 300–500 行）；可复用 `dpb587/metalink`（MIT）的 v4 结构体，**禁用 `libmetalink`（C 库，引入 cgo）**。
- 视为不可信输入：XML 大小上限（默认 4MiB）、镜像数量上限（默认 32）、禁止 DTD/外部实体、逐 URL 过 SSRF Guard、整文件与分块哈希必须校验。

## 8. 开发、调试与发布流程

1. `udctl plugin scaffold <name>` 生成 manifest + 样例 + 本地测试夹具。
2. `udctl plugin verify <dir>` 做 manifest 校验、签名校验、静态禁用 API 扫描。
3. `go test ./test/plugin/...` + `udctl plugin test <dir> --fixture cases.json` 跑录制回放用例（禁止测试直连真实站点）。
4. 提交到规则仓库 → CI 跑沙箱用例 + 许可证扫描 → 签名发布。
5. 客户端从独立规则通道拉取，校验签名后热加载；**规则包更新与主程序发版解耦**。
6. 规则失效遥测（默认关闭、需用户同意）只上报 `plugin name + version + error code`，不上报 URL 与凭据。

## 9. 评审清单（PR 必查）

- [ ] manifest `capabilities` 最小授权，无 `subprocess` / `fs` / `env`
- [ ] 所有 URL 经 `ctx.http` 白名单与 SSRF Guard
- [ ] 有超时、内存、响应大小限制；有 `RULE_OUTDATED` 明确错误
- [ ] 不读取、不打印、不回传凭据
- [ ] 产出 `Resource` 符合 `05` §3 / `06` §4 schema
- [ ] 不自行写文件、不自行下载（Resolver 只描述）
- [ ] 许可证兼容、签名有效、有回放测试用例
