## 1. 测试金字塔与分层

| 层 | 范围 | 工具 | 目标 | 运行时机 |
|---|---|---|---|---|
| L1 单元 | 纯函数、状态机、解析器、Remux 组件 | `go test`、fuzz | `core`/`security` ≥ 90%；`store`/`scheduler`/`transport/http`/`api`/`config`/`postproc`/`resolve`/`app` ≥ 80%；`cmd/*` 与 `internal/version` 只报告不设门禁（口径见 §8、`17` §3） | 每次提交 |
| L2 契约 | `Resource` JSON 往返、REST/WS/CLI schema、错误码 | `go test` + schema 校验 + 契约测试 | 接口零漂移 | 每次提交 |
| L3 集成 | Transport + Store + Scheduler 全链路（本地 fixture 服务器） | `httptest`、本地 FTP/SFTP、自建 tracker | 分片/续传/限速/重试正确 | 每次 PR |
| L4 **互操作** | 真实 BT 客户端、tracker、eMule 网络 | 容器化真实客户端 | 见 §3，全矩阵通过 | 每日 + 发布前 |
| L5 端到端 | UI/CLI → daemon → 落盘 → 后处理 | 自动化脚本 + 录制回放 | 关键用例 UC-01..UC-08 通过 | 每日 |
| L6 非功能 | 性能、故障注入、安全、兼容性 | 见 §4–§6 | 达到 NFR 指标 | 发布前 |

**原则**：站点解析测试一律用**录制回放 fixture**，禁止 CI 直连真实站点（规则会变、违反 ToS、结果不稳定）；真实站点只做人工冒烟。

## 4. 故障注入

| 场景 | 期望 |
|---|---|
| 进程 `kill -9` 后重启 | 已落盘分片 100% 复用，无重复下载、无损坏 |
| 分片被外部篡改 | 校验失败 → 只重下该片 |
| 镜像全部失败 / 部分失败 | 切换镜像；达上限才判失败 |
| tracker 超时 / DNS 失败 / 5xx | 指数退避 + 降级，不阻塞其他任务 |
| 磁盘写满 / 只读目录 | `E_STORAGE_FULL`，任务暂停且可恢复 |
| sidecar 崩溃、无响应、版本过低 | 自动重启 3 次；最终 `degraded`；其余下载不受影响 |
| ffmpeg 执行中用户取消 | 进程组/进程树被杀，无残留写文件 |
| 恶意 Metalink（私网 URL、超大 XML、镜像 1000 个） | SSRF/上限拦截，无 OOM |
| 恶意 m3u8（路径穿越、`file://`、超多分片） | 拦截并告警 |
| 插件死循环 / 抛异常 | 超时强杀，任务转 `E_RESOLVE_FAILED` |

| 移动端 BT 内存 | ≤ 150MB | 真机 |

## 6. 安全与兼容性测试

- SSRF 用例集：私网 / 回环 / `169.254.169.254` / IPv4-mapped IPv6 / DNS 重绑定 / 3 跳重定向到内网 / 非标端口 / `file://` / `gopher://`。
- 凭据泄漏扫描：日志、事件、REST 响应、崩溃报告全量正则扫描 `cookie|authorization|passkey|session`。
- 路径穿越：`../`、绝对路径、符号链接、Windows 保留名。
- 依赖扫描：`govulncheck` + SBOM 许可证检查（GPL 不得出现在传输路径）。
- ffmpeg：能力协商失败降级、LGPL 构建校验、缺 ffmpeg 时 yt-dlp 画质退化用例（验证我方 formats 选取绕开该陷阱）。
- L1 facade：以 **AriaNg 为验收套件**（新建/暂停/恢复/删除、多文件选择、限速、全局统计、WS 刷新）。
