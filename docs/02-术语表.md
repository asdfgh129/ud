# 02 术语表

> 文档编号：UD-DOC-02 ｜ 版本：v0.1 ｜ 状态：草案 ｜ 日期：2026-11-08

本表是全项目唯一术语基准。特别注意 §1：项目里最容易返工的错误，就是把「协议 / 链接封装格式 / 内容源解析器」混为一谈。

## 1. 三类输入的严格区分

| 术语 | 定义 | 例子 | 在本项目中的归属 |
|---|---|---|---|
| **传输协议** Transport Protocol | 真正负责把字节从远端搬到本机的协议 | HTTP/HTTPS、FTP/FTPS、SFTP、BitTorrent、ed2k、HLS/DASH 分片取流 | `Transport` 实现 |
| **链接封装格式** Link Wrapper | 一个或多个真实 URL + 校验/优先级元信息的容器，**自身不传输字节** | `thunder://`、`flashget://`、`qqdl://`、Metalink v3/v4、Metalink-HTTP | `Resolver` 解析成 `Resource` |
| **内容源解析器** Content Resolver | 把页面/账号/会话/消息解析为带 Header/Cookie 的真实流地址 | 视频网站、Telegram、微信视频号 | `Resolver` 实现 |

> 规范用语：`thunder://` 只能叫「链接封装格式」或「专有链接」，不得称为「迅雷协议实现」；「迅雷 P2SP」才是真正的私有协议，本项目不支持。

## 2. 核心架构术语

| 术语 | 英文 / 缩写 | 定义 |
|---|---|---|
| 流水线 | Pipeline | `输入 → Resolver → Resource → Transport → 落盘 → PostProcessor` 的唯一处理链 |
| 解析器 | Resolver | 将任意输入解析为统一资源描述的组件；不下载、不写文件 |
| 资源描述 | Resource | 流水线中枢数据结构：目标、协议、多文件布局、镜像、校验、协议身份、凭据引用 |
| 传输后端 | Transport | 按 `Resource` 执行实际字节传输的组件，受核心调度器统一支配 |
| 后处理器 | PostProcessor | 下载完成后对**本地文件**做 remux / 转码 / 字幕处理的组件 |
| 任务 | Task | 用户可见的下载单元，持有状态、进度、限速、优先级与一个 `Resource` |
| 分片 | Chunk / Piece | HTTP 分段称 Chunk；BT 校验块称 Piece。两者都映射到统一 `chunks` 表 |
| 调度器 | Scheduler | **唯一**拥有队列、并发、限速、重试、状态迁移的权威组件 |
| 单调度器原则 | Single Scheduler | 禁止任何外部进程/库自行管理任务生命周期（双调度器反模式） |
| 守护进程 | Daemon | 常驻 Go 进程，承载核心与 REST/WS 服务；UI 与之分离 |
| 边车 | Sidecar | 为满足运行时差异/许可证/提权/热更新而外置的独立进程 |
| 零 sidecar 基线 | Zero-sidecar Baseline | 仅传输协议（含 BT/ed2k/FTP）时，核心以 1 进程完成全部工作 |
| 兼容子集 | Compat Subset | 对外声明支持的 aria2 JSON-RPC 方法集合（约 25 个），不承诺 100% |
| 能力协商 | Capability Negotiation | 启动时探测外部组件版本/构建配置，缺失则降级对应功能 |

## 3. 传输与流媒体术语

| 术语 | 定义 |
|---|---|
| Range 分段 | HTTP `Range` 请求并发拉取不同字节区间，支持断点续传 |
| Progressive | 音视频已合流在单一文件中的格式（可"只下载"直接播放） |
| Adaptive Streaming | 音视频分离的 HLS / DASH，需分别下载后合并 |
| HLS / m3u8 | Apple 的 HTTP Live Streaming；分片常为 MPEG-TS 或 fMP4 |
| DASH / MPD | MPEG-DASH，清单为 MPD XML，分片常为 fMP4/CMAF |
| AES-128 | HLS 常见分片加密，纯 Go `crypto/aes` 即可解密 |
| EXT-X-DISCONTINUITY | HLS 中时间戳/编码参数不连续标记，remux 时必须重基准 |
| Remux / Transmux | 只换容器、不重新编码像素（TS→MP4 等），**不等同转码** |
| Transcode | 解码后重新编码（改分辨率、转 MP3、烧字幕），需编解码器 |
| PTS/DTS 重基准 | 把 TS 基于 PCR 的、可跳变/回退的时间戳，转成 MP4 `stts` 要求的单调递增非负序列；属 remux 固有步骤 |
| Annex B → AVCC | H.264 从 TS 的起始码格式转为 MP4 `avcC`（SPS/PPS）格式 |
| ADTS AAC | TS 中音频封装形式，remux 时转为 MP4 sample |
| moov / faststart | MP4 索引盒；移到文件头以支持边下边播 |
| CENC | 通用加密（fMP4），与 DRM 不同，本项目仅处理未加密或已授权明文 |

## 4. BitTorrent 术语

| 术语 | 定义 |
|---|---|
| BEP | BitTorrent Enhancement Proposal，协议扩展规范编号 |
| Infohash (v1) | SHA-1 of `info` 字典，20 字节 |
| btmh | BitTorrent v2 的 infohash（SHA-256），magnet URI 中的 `btmh` 参数 |
| Hybrid Torrent | v1/v2 混合种子；本项目默认只生成/使用 v1 或 hybrid |
| Magnet / 磁力 | 不含 .torrent 文件的链接，靠 infohash + DHT/metadata 交换获取元数据 |
| DHT / PEX / LSD | 分布式哈希表 / 对等节点交换 / 局域网组播发现（BEP 5 / 11 / 14） |
| uTP | 基于 UDP 的拥塞控制传输（BEP 29） |
| MSE/PE | 消息流加密 / 协议加密 |
| WebSeed | 从 HTTP 服务器取分片（BEP 19） |
| Private Flag | BEP 27 私有种子标记，要求关闭 DHT/PEX/LSD，只用 tracker |
| PeerID | 客户端身份串；本项目默认 `-GT0001-`，**保持诚实不伪装** |
| Passkey | PT 用户附在 announce URL 中的私有凭据，不得进日志 |
| Tracker / Announce / Scrape | peer 发现服务 / 汇报 / 统计查询；HTTP、UDP、HTTPS 三类 |
| Seed / H&R | 做种 / Hit-and-Run（下完不传），PT 站会处罚 |
| Super-seeding | BEP 16 初始做种优化，当前库未实现 |

## 5. eD2k / eMule 术语

| 术语 | 定义 |
|---|---|
| eD2k Server / server.met | 中心服务器与服务器列表文件 |
| Kad / KadV6 / nodes.dat | Kademlia DHT 网络与引导节点列表 |
| High ID / Low ID | 是否有可入站 TCP 4662 端口；Low ID 只能看到部分源 |
| AICH | 高级智能损坏处理，分块哈希树 |
| Secure Ident | RSA 2048 客户端身份认证，防积分窃取 |
| CryptLayer / 混淆 | 协议混淆；部分客户端设为「仅混淆」会拒绝明文连接 |
| Credit / clients.met | 双向按客户端对计的上传积分，决定排队优先级 |
| Source Exchange | 客户端之间交换已知源 |
| Collection | 多文件链接集合 |

## 6. 外部组件与工程术语

| 术语 | 定义 |
|---|---|
| goja / wazero / Extism | 纯 Go JS 引擎（ES5.1）/ WebAssembly 运行时 / WASM 插件框架 |
| cgo | Go 调用 C 的机制；启用即破坏纯 Go 单二进制交叉编译 |
| MTProto | Telegram 原生协议；Bot API `getFile` 仅支持 20MB，大文件必须走 MTProto |
| EJS | yt-dlp 的外部 JS 挑战求解（YouTube `n` 参数 / sig 签名），需 Deno 或 Node |
| PO Token / SABR | YouTube 的 attestation 与流式响应机制，属持续对抗面 |
| MITM | 中间人代理（微信视频号嗅探用 `goproxy` + 自签 CA） |
| SSRF | 服务端请求伪造；Resolver 处理不可信 URL 时的首要风险 |
| W^X | Android 10/API 29+ 禁止执行应用私有目录文件的限制 |
| Remux 内置 / Transcode 可选 | `PostProcessor` 的两个实现层级 |
| LGPL / GPL / MPL / MIT / ISC | 依赖许可证类型；详见 `10` |
| SBOM | 软件物料清单 |
| DoR / DoD | 就绪定义 / 完成定义 |
