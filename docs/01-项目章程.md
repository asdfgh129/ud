# 01 项目章程

> 文档编号：UD-DOC-01 ｜ 版本：v0.1 ｜ 状态：草案（待立项评审） ｜ 日期：2026-11-08 ｜ 批准人：待定

## 1. 项目标识

| 项 | 内容 |
|---|---|
| 项目名 | Universal Downloader（通用下载器），代号 **UD** |
| 产品形态 | 常驻守护进程（daemon）+ 跨平台客户端；另提供 Headless / CLI 形态 |
| 核心交付 | 纯 Go 单二进制下载引擎，传输层零外部进程 |
| 目标平台 | Windows / macOS / Linux（桌面优先）；Android / iOS（移动端，能力子集）；服务器 / NAS（headless） |
| 文档基线 | 2026-11-08 架构讨论结论 + 七轮追问修订（见 `adr/`） |

## 2. 问题陈述

现有下载工具按「一个协议一个实现」堆叠，导致：进度与限速各自为政、断点状态多份真值源、每加一个来源就要重做队列；视频站解析与传输耦合，无法统一调度；桌面方案依赖 `aria2c` 等子进程，移动端（iOS 禁止派生子进程、Android W^X）直接不可达；GPL 依赖与私有协议边界不清，商用与合规风险高。

## 3. 愿景与目标

**愿景**：任何可定位到字节流的来源，都能进入同一条可观测、可限速、可恢复的下载流水线。

| 层级 | 目标 | 度量 |
|---|---|---|
| 业务 | 覆盖主流传输协议、链接封装与内容源，替代多工具并用 | 支持来源类别 ≥ 8 类；单一队列管理全部任务 |
| 产品 | 统一任务体验：暂停/恢复/限速/优先级/断点/进度 | 所有来源的任务操作语义一致，无来源特例 |
| 技术 | 单调度器、纯 Go 单二进制、传输层零 sidecar | `CGO_ENABLED=0` 交叉编译通过 6 个目标；传输路径进程数 = 1 |
| 生态 | 插件可热更新站点规则；可选兼容 aria2 RPC 生态 | 新增站点无需重发主程序版本 |
| 合规 | 依赖许可证清晰、能力边界声明明确 | 无 GPL 组件进入传输热路径；SBOM 可生成 |

## 4. 范围（In Scope）

1. **传输协议**：HTTP/HTTPS（多线程分段、Range、断点）、FTP/FTPS、SFTP、BitTorrent / 磁力（DHT/PEX/uTP/WebSeed/私有 flag）、ed2k（eD2k server + Kad）、HLS/DASH 流媒体取流。
2. **链接封装格式**：`thunder://`、`flashget://`、`qqdl://` 解码；Metalink v3/v4（RFC 5854）与 Metalink-HTTP（RFC 6249）多源清单解析。
3. **内容源解析器**：中文视频站（`lux` 进程内）、长尾/YouTube（`yt-dlp` 仅吐 JSON）、Telegram（`gotd/td` 纯 Go）、微信（可选隔离插件）。
4. **后处理**：纯 Go Remux（默认内置）；可选 Transcode（ffmpeg，桌面插件）。
5. **平台能力**：任务队列、全局限速、断点续传、哈希校验、插件引擎、SQLite 持久化、REST/WS/CLI、凭据管理、可观测性。

## 5. 非目标（Out of Scope）——必须写进产品文案

| 编号 | 非目标 | 原因 |
|---|---|---|
| NG-01 | 迅雷 P2SP 加速 / 高速通道 / 离线下载 | 私有协议，无开源实现；仅做 `thunder://` Base64 解码得到直链 |
| NG-02 | 私有 tracker（PT）准入承诺 | 站点按 PeerID + 扩展握手白名单，伪装违反规则且易被反作弊识别；只声明兼容标准 BT 网络 |
| NG-03 | ed2k 下载速度承诺 | 网络活跃度低，速度受积分、Low ID、在线源数量支配 |
| NG-04 | DRM（Widevine / FairPlay / PlayReady）内容解析 | 法律与平台条款风险，明确不碰 |
| NG-05 | Metalink 全生态投入 | 生态事实性衰退（curl 7.78.0 已移除），按容器格式处理，不进核心排期 |
| NG-06 | 微信视频号嗅探随主包分发 | 涉及逆向、MITM CA、系统代理提权，单独分发、默认不安装 |
| NG-07 | 100% aria2 RPC 兼容 | 只声明 compat subset（约 25 个方法），长尾不追 |
| NG-08 | 同文件跨协议混合拉流（HTTP+FTP+BT 取同一文件不同分片） | 移除 aria2 后不再现成具备；列为远期可选能力 |
| NG-09 | 内置浏览器 / 通用爬虫 | 只做用户显式提交来源的解析 |
| NG-10 | 网盘服务端、离线转存、P2P CDN 商业化 | 超出本项目范围 |

## 7. 成功指标（可度量）

| 指标 | 目标 |
|---|---|
| 任务操作一致性 | 100% 来源支持暂停/恢复/取消/限速，语义一致 |
| 断点恢复 | 进程崩溃后重启，已落盘分片 100% 可复用，无重复下载 |
| 传输层外部进程数 | 桌面 0（零 sidecar 基线）；启用 YouTube 时全功能版 2 |
| 跨平台 | `CGO_ENABLED=0` 下 6 个目标平台构建通过；移动端 BT 可用 |
| 依赖合规 | 传输路径 GPL 依赖数 = 0；所有二进制依赖有 sha256 + buildconf 溯源 |
| 互操作 | 与 qBittorrent / Transmission 双向做种下载通过；自建 tracker 全矩阵通过 |
| 插件能力 | 新增一个站点规则不需重发主程序版本 |
| 崩溃隔离 | 任一 sidecar 缺失/崩溃不阻塞其余下载任务 |

## 8. 关键约束

| 编号 | 约束 | 来源 |
|---|---|---|
| C-01 | 核心必须保持纯 Go、无 cgo、单二进制，禁止为任何外部能力让步 | ADR-0001 |
| C-02 | 调度器唯一；禁止引入第二个任务生命周期管理者 | ADR-0002 |
| C-03 | 不捆绑 `aria2c`；保留其 wire protocol 规范作为可选 L1 facade | ADR-0003 |
| C-04 | `Resource` 模型在 P0 一次性纳入协议身份字段与多文件输出 | ADR-0013 |
| C-05 | `PostProcessor` 输入必须是本地文件路径，输出 `.part` + 原子提交 | ADR-0012 |
| C-06 | P2P 保持诚实 PeerID，禁止伪装客户端 | ADR-0017 |
| C-07 | 移动端不依赖任何派生子进程的能力 | ADR-0008 / ADR-0011 |
| C-08 | 任何外部依赖缺失只降级对应功能，绝不阻塞下载 | ADR-0008 |

## 9. 假设与依赖

- 假设 Go 1.2x 工具链可覆盖全部目标平台；`modernc.org/sqlite` 在移动端可用。
- 假设 `anacrolix/torrent`、`goed2k` 持续维护；`goed2k` 为 v0.1.0 新库，需自建互操作回归（风险 R-06）。
- 依赖外部生态：站点规则（yt-dlp 社区）、ffmpeg LGPL 构建源、Telegram MTProto 协议稳定性。
- 依赖用户自备：Telegram 账号凭据、部分站点 Cookie、私有 tracker 的 passkey（不承诺 PT）。

## 11. 立项风险摘要

最高三项：`goed2k` 互操作未充分回归（R-06）、站点规则长期维护成本（R-04）、ffmpeg 跨平台二进制矩阵与许可证（R-07）。完整登记册见 `14-项目计划与风险管理.md`。
